# 3D-First-Game-Of-TajsGames
# Midnight Chase: Twilight's Shadow

A 3D HTML5 browser game where the player controls **Twilight Sparkle** as she tries to escape from **Midnight Sparkle**, who is relentlessly pursuing her. This project marks the very first 3D game developed by **TajsGames**.

## Features
* **3D Gameplay:** Fully rendered in 3D right in your web browser.
* **Dynamic AI:** Midnight Sparkle tracks and follows the player continuously.
* **Responsive Controls:** Smooth movement mechanics designed for desktop browsers.

## How to Play
1. Open `index.html` in any modern web browser.
2. Use the **W, A, S, D** or **Arrow Keys** to move Twilight Sparkle.
3. Evade Midnight Sparkle for as long as possible!

## Technologies Used
* HTML5 / CSS3
* JavaScript (WebGL / Three.js)
